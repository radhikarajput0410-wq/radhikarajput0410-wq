# ⚡ How to Deploy Your Cyberpunk GitHub Profile README

Follow these simple steps to set up your unique GitHub profile page!

---

### Step 1: Create Your Special GitHub Repository

1. Go to [GitHub New Repository](https://github.com/new).
2. Set the **Repository Name** to your exact GitHub username:
   ```text
   radhikarajput0410-wq
   ```
   *(GitHub will show a special banner: ✨ "You found a secret! radhikarajput0410-wq/radhikarajput0410-wq is a special repository...")*
3. Make sure the repository visibility is set to **Public**.
4. Check **Add a README file** (or leave unchecked if you plan to push from your computer).
5. Click **Create repository**.

---

### Step 2: Upload Files to the Repository

You can upload the files directly via GitHub Web Interface or Git command line:

#### Option A: Via GitHub Web Interface
1. Open your repository: `https://github.com/radhikarajput0410-wq/radhikarajput0410-wq`
2. Drag & Drop or upload these files:
   - `README.md`
   - `header-banner.svg`
   - `.github/workflows/snake.yml` (Make sure it's inside `.github/workflows/` folder)
3. Click **Commit changes**.

#### Option B: Via Git CLI (Recommended)
Open your terminal inside this `github update` folder on your computer and run:

```bash
git init
git add .
git commit -m "feat: setup cyberpunk AI/ML profile README"
git branch -M main
git remote add origin https://github.com/radhikarajput0410-wq/radhikarajput0410-wq.git
git push -u origin main --force
```

---

### Step 3: Enable Permissions for Snake Animation Workflow

To make the **Animated Contribution Snake** work automatically:

1. In your `radhikarajput0410-wq` repository, click **Settings** (top navigation bar).
2. On the left sidebar, click **Actions** ➔ **General**.
3. Scroll down to **Workflow permissions**.
4. Select **Read and write permissions**.
5. Click **Save**.

---

### Step 4: Run the Snake Action for the First Time

1. Go to the **Actions** tab in your repository.
2. On the left sidebar, click **Generate Snake Contribution Grid**.
3. Click **Run workflow** dropdown on the right ➔ Click the green **Run workflow** button.
4. Wait ~30 seconds for the green checkmark ✅.

---

Visit your GitHub profile at [`https://github.com/radhikarajput0410-wq`](https://github.com/radhikarajput0410-wq) to see your brand new Cyberpunk / Dark Neon AI Engineer profile!
